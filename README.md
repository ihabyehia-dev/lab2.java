# Java Lab 2 - Integer Array Operations

This is another version of the integer-array data structures exercise, with `ArrayyInt.java`, `Main.java`, and an Eclipse module descriptor.

## What it practices
- Fixed-capacity arrays and tracking the number of stored elements
- Insert at front, back and a selected position
- Linear search and deletion by value
- Displaying values and computing simple statistics

## Run
In Eclipse, create a Java project and put `ArrayyInt.java` and `Main.java` into package `solutionlab1`. Run `Main.java`. If your Eclipse project has no module setup, you may remove `module-info.java` from your **local** non-modular copy.

## Notes
The implementation now handles full-array insertion and average calculations without an error for empty even-number sets; it also includes working linear search and selection sort. Test empty/full arrays and missing values. This remains a classroom exercise.
